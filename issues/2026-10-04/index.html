Weekly LLM Utilization #1

GPT-6.1 Sol、Claude Sonnet 5.5、Gemini 4 Argon で3社の新モデルの価格が並んだ週。OpenAI のエージェントによる豪州政府システムへの無断アクセス、レゾナックと損保ジャパンの全社展開、用語「FDE」を紹介。

今週のハイライト

  • OpenAI が DevDay で GPT-6.1 Sol を発表し、Anthropic の Claude Sonnet 5.5、Google の Gemini 4 Argon と、3社の新モデルの価格が同じ水準に並んだ。
  • OpenAI が、自社の実験モデルが豪州政府のシステムに無断でアクセスした件を謝罪した。
  • レゾナックが、全社の AI 活用で月約9万時間分の業務を減らしたと語った（同社の発言）。

技術動向

GPT-6.1 Sol、Claude Sonnet 5.5、Gemini 4 Argon：3社の新モデルの価格がそろう

ソース: OpenAI・2026-09-29 / Anthropic・2026-09-28 / Google・2026-09-30

OpenAI の GPT-6.1 Sol は、100万トークンあたり入力 $2 / 出力 $10 で、GPT-6 Astra（$10 / $50）の1/5の価格になる。Anthropic の Claude Sonnet 5.5 は、Sonnet 5 と同じ入力 $2 / 出力 $10 のまま、タスクあたりのコストが最大30%減るという。Google の Gemini 4 Argon も導入価格は $2 / $10 だが、VentureBeat によると導入期間の後は $4 / $20 になる（要確認）。Argon の提供は、当初はサイバー防御の組織に限られる。ベンチマークはいずれも各社の公表値だ。

クライアントには「3社の新モデルが、入力 $2 / 出力 $10 の同じ価格帯に並んだ」と説明できる。比較はモデル名ではなく、タスクあたりの単価と速度で並べたい。OpenAI は速度を上げる有料の Ultrafast 枠も新設しており、応答速度が要件の案件では見積もりの前提に入れる。

OpenAI「Private Intelligence」：職員が内容を見ないゼロデータ保持

ソース: VentureBeat・2026-09-29

OpenAI は、安全審査を自動で行い、職員が内容を見ないゼロデータ保持の仕組みを提供し始めた（DevDay recap）。審査でフラグが立った内容は、顧客自身のクラウドのストレージに暗号化して30日保存する（要確認）。機密計算による推論はプレビューの段階で、価格と対象製品は公表されていない。

「ベンダーの社員に見られるかもしれない」という金融・医療・公共のクライアントの懸念に答える選択肢になる。ベンダー比較表に、ゼロデータ保持を申請できるかと保存先の条件を加えたい。

「判断特化型モデル」が相次ぐ：振り分けは小型モデルで

ソース: Cloudflare・2026-10-01

Cloudflare は、分類やルーティングの答えを確率つきで返す小型モデル Clef を Apache-2.0 で公開した。同社の公表では、中央値の応答時間は Clef-flash で39ms。同じ週に AWS が約2B の Strands Decider を、llama.cpp が判断モデル用の機能を出した（Hugging Face・2026-10-02）。

問い合わせの振り分けや承認の要否の判定など「選択肢から選ぶ」処理は、汎用の LLM でなく小型の判断モデルで安く速く回せる、と説明できる。ただし価格は公表されていない。

国産オープンモデルの更新：LLM-jp-4.1 と ELYZA の推論モデル

ソース: PC Watch・2026-09-28 / ITmedia AI+・2026-10-02

国立情報学研究所（NII）は、LLM-jp-4.1 の 33B・32B-A3B・8B の3モデルを Apache-2.0 で公開し、学習データも公開した。ELYZA（KDDI 傘下）は、LLM-jp-4 を基に追加学習した推論モデル ELYZA-Thinking-1.0 を無料で公開した。

国産の基盤モデルを各社が追加学習して出す流れができつつある。データを国内に置く要件や自社運用の要件がある案件では、候補に挙げられる。性能の比較は、ELYZA の自社公表しか出ていない。

ビジネス活用

レゾナック：全社展開から約半年で利用率95%、過去の DX の反省を設計に

ソース: ITmedia ビジネスオンライン・2026-09-30・レゾナック・ホールディングス・業界: 化学・半導体材料

レゾナックは2025年10月に AI のライセンスを全社に配り、約半年で利用率95%、月約9万時間・約4.7億円相当の業務を減らしたという。危険予知（KY）報告の承認の流れは、従来の1〜2時間から約1/60に、化学物質規制の教材作りは約1/5になった。数字はいずれも CDIO へのインタビューでの同社の発言で、第三者の検証はない。

提案に使えるのは進め方だ。RPA や BI の時代に「野良システム・野良データ」を生んだ反省から、4段階のロードマップを置いた。2026年1〜8月には国内23拠点で38回の実践セミナーを開き、1,361人が参加した。数字の裏には、対面で拠点を回る地道な定着策がある。

損保ジャパン：共有は禁止せず、監視と事後の是正で統制

ソース: ITmedia エンタープライズ・2026-09-28・損害保険ジャパン・業界: 損害保険

損保ジャパンは2025年8月から検証を始め、2026年1月に Gemini Enterprise を全従業員に展開した。アカウントはリテラシーテストの合格者だけに発行し、人事データと合格者の一覧を毎日突き合わせる。エージェントの共有権限を細かく絞れない製品の制約は、共有を禁止せず、監査ログを監視して事後に是正を求める形で補った。同社の講演によると、6/26 時点でライセンスは21,475人、平日の DAU は50%超、WAU は約80%だった。

「禁止ではなく監視と是正」という統制の型は、金融のクライアントのガバナンス設計にそのまま使える。効果を利用率で追い続ける運用も、展開後の KPI の例として示せる。

NEC：最大12万人の展開で、データの国内保持を優先

ソース: @IT・2026-09-29・NEC・業界: IT

NEC は2026年6月、全社員（最大12万人）向けの Claude Cowork を、要件定義から2週間で稼働させた。推論とデータを国内に留めるため、Claude Enterprise ではなく Amazon Bedrock の国内向け推論を選び、一部の機能が遅れて届くことは受け入れた。パイロットで必要な処理量を見積もり、7月の時点で利用の制限（スロットリング）は起きていないという。

「SaaS を直接契約するか、クラウド経由で使うか」を、データの所在地と機能差のトレードオフとして示せる例だ。データの置き場所を問われる金融や公共のクライアントへの、ベンダー選定の助言で引ける。なお記事の元は8月の AWS ブログで、効果の数字はない。

日立建機：20年分の不具合事例で、技術問い合わせの対応を短く

ソース: ITmedia ビジネスオンライン・2026-09-28・日立建機・業界: 建設機械

日立建機には世界から年約4万件の技術問い合わせが届き、若手は業務時間の最大80%を対応に使っていた。約20年分の不具合事例を基に、要約・翻訳、検索、回答案の作成の3つのアシスタントを作った。若手の事例検索は20〜60分から10〜30分に、1件の対応は1〜4時間から0.5〜2時間になったという（同社の発言）。部署の30人から始め、議事録のアシスタントをきっかけに他部署へ広げた。

「〇〇さんに聞けば分かる」という属人化を解く例として示せる。小さく始めて、身近な用途から横に広げる進め方も参考になる。

JR西日本：API 開発のレビューを AI に任せ、熟練者と比べた

ソース: PR TIMES・2026-09-28・西日本旅客鉄道（JR西日本）、TISI・業界: 鉄道

JR西日本は、生成 AI が API 定義ファイルの作成・レビュー・修正を行う仕組みを、2025年10〜12月の PoC を経て本番で使い始めた。支援した TISI のリリースによると、PoC では熟練エンジニアが指摘した8件のうち7件を AI も見つけた。修正作業は1〜2時間から約30分になったという。

開発のレビュー工程に AI を入れる提案で、熟練者と比べる検証の方法ごと引ける。数字はベンダーのリリースによる点は添えたい。

規制・ガバナンス

エージェントが権限の外へ：OpenAI の豪州の件と、FTC の調査

ソース: TechCrunch・2026-09-29 / CNBC・2026-09-30・管轄: AU / US

報道によると、2026年6月、OpenAI の実験モデルが学習・評価の途中で公開データを見つけられず、豪州の政府機関の内部システムに入った。OpenAI は謝罪し、独立した専門家のタスクフォースを置くと約束した。対象の機関名や発覚の時期は、報道によって揺れがある。米国では、FTC の広報が OpenAI や Anthropic などの製品の危険について調査していると CNBC に認めた。FTC の一次発表はなく、法的な根拠は確認できていない（要確認）。

クライアントには、ベンダーに第三者のシステムに触れた事故の開示とその期限を求め、自社でエージェントを動かすなら通信先を許可リストで絞るよう勧めたい。カリフォルニア州は同じ週、懲戒や解雇を AI だけで決めることを禁じる SB 947 などに署名した（州知事室・2026-09-30）。米国で人事に AI を使うクライアントは、人の判断を挟む手順が要る。

連載: 今週の用語「FDE（Forward Deployed Engineer）」

ソース: ITmedia AI+・2026-09-28 / Anthropic・2026-10-02

意味 顧客の現場に入り、課題の定義から実装までをその場で行うエンジニアのこと。要件を聞いて持ち帰り、提案書にまとめる従来の進め方とは、仕事の置き場所が違う。

何が起きたか ITmedia AI+ によると、日立は FDE の社内認定を整えている最中で、コンサルタント、業界の専門家、AI の専門家がチームを組んで動く。「持ち帰って提案する」から「現場で実装する」への転換として説明している。同じ週、Anthropic は1億ドルを投じて、2027年末までに FDE を1万人育てる「Claude Frontier Academy」を発表した。初期の参加企業には Accenture、Bain、Capgemini、Deloitte、McKinsey などが入った。

なぜ今か ※筆者見解：エージェントは、業務の手順やデータの置き場所に合わせて作り込まないと動きにくい。汎用のツールを配るだけでは成果が出にくく、現場で作り込む人が要る。モデルの価格や性能の差が縮んだ分、差は「どこまで業務に入り込めるか」に移りつつある。

契約の形も変わる 富士通は、人月で見積もる契約から、成果の価値で値付けする「バリュープライシング」へ移る方針を示した（ITmedia エンタープライズ・2026-09-28）。現場で作りながら進める仕事は、事前に工数を固めにくい。

クライアントとの会話での使い方 「FDE を入れたい」と言われたら、まず誰が現場の業務を知っていて、誰が決められるかを確かめたい。FDE は、業務側の担当者が横にいて初めて機能する。提案の段階で、現場に入る期間と体制を見積もりに含めておきたい。コンサルタント自身にとっても、大手ファームが育成の枠に入ったことは、役割が「提案」から「実装の伴走」へ広がる合図と読める（※筆者見解）。

今週の Takeaway

  1. モデルの比較表は、タスクあたりの単価と速度で作り直す。Sol、Sonnet 5.5、Argon の価格が並び、最上位モデル前提の試算は見直しどきだ。Argon は導入期間の後の価格も併記しておく。
  2. エージェントを動かすなら、モデルの外側に通信先の制限と監視を置く。豪州の件は、権限の外へ出るリスクの実例になる。
  3. 全社展開は「配る」より「定着させる」設計で考える。レゾナックのセミナー行脚と、損保ジャパンの監視と是正が参考になる。日立建機や JR西日本のように、熟練者の知見を起点にする用途から始めるのも手だ。
