技術動向

Claude Haiku 5.5：大量処理の単価が1桁下がる

ソース: Anthropic・2026-10-07

Anthropic は、要約・分類・DB クエリなどの大量処理に向けた小型モデル Claude Haiku 5.5 を公開した。料金は、100k トークン以下のプロンプトで入力 $0.10 / 出力 $0.50 per 1M。Haiku 4.5（$1.00 / $5.00）の10分の1になる。Haiku 系で初めて effort の設定を持ち、AWS・Google Cloud・Azure を含む全プラットフォームで使える。同時に Sonnet 5.5 のキャッシュ読み込みの料金を半額にし、多くのエージェント処理で Sonnet 5.5 のコストが約20%下がるという（同社の発表）。

クライアントには「上位モデルで計画し、小型モデルに下請けさせる構成の単価の前提が変わった」と説明できる。問い合わせの分類や要約の試算は、単価を差し替えて作り直す価値がある。ベンチマークは自社公表で、コンテキスト長は発表に記載がない。

GPT-6 が ChatGPT の全プランに：変わるのは Chat だけ

ソース: OpenAI・2026-10-07

OpenAI は ChatGPT に GPT-6 を展開した。Plus / Pro / Business / Enterprise は GPT-6 Sol、Free / Go は翌日から GPT-6 Luna を使う。回答の中に画像・ボタン・フォーム・グラフなどの操作できる要素が入り、計算機のような小さなツールもその場で作る。Enterprise で使えるかどうかは、ワークスペースの管理者の設定による。ChatGPT Work と Codex のモデルは据え置きだ。

社内で ChatGPT を配っているクライアントには、利用ガイドや研修資料の更新と、管理者設定の確認を勧めたい。API の提供と価格は発表に記載がない。

Gemini agent：Google の業務エージェントで Claude も選べる

ソース: TechCrunch・2026-10-08

Google は Gemini at Work 2026 で、業務用の汎用エージェント「Gemini agent」を発表した。目的を渡すと計画を立て、Workspace、Microsoft 365、Slack、Jira、BigQuery、MCP サーバーなどにつないで作業する。既定ではタスクごとにモデルを選び、ユーザーは Anthropic の Claude も指定できる。エージェントは自分の Workspace アカウントを持ち、監査記録はエージェントの名義で残る。

Google 陣営でも、1つの画面で複数社のモデルを切り替える形になった。ガバナンスの設計では、エージェント名義の監査ログと支出上限を確認項目にできる。価格と GA の時期は未公表で、Google Cloud の一次発表は本稿では確認できていない。

ビジネス活用

かんぽ生命：営業報告を AI が下書きし、人が確認して登録する

ソース: キーマンズネット・2026-10-08・かんぽ生命保険・業界: 生命保険

かんぽ生命は、顧客との対話データから報告に必要な項目を AI が抽出・構造化し、Salesforce に連携する「bellSalesAI」を、全国の法人営業部門の約1,200人に導入した。担当者は、AI が抽出した内容を確認してから登録する。記事によると、商談1件あたりの報告時間は約50分から約10分になった（要確認。一次の発表は未確認）。

営業日報や商談報告の入力の負荷は、多くの業界に共通する。「AI が下書きし、人が確認して登録する」型は、登録の責任を担当者に残したまま導入できるので提案しやすい。提案では、削減時間の試算に「確認にかかる時間」を含めておきたい（※筆者見解）。

千代田区と取手市：「全員に使わせる」か「使う人から広げる」か

ソース: キーマンズネット・2026-10-08・東京都千代田区 / 茨城県取手市・業界: 自治体

千代田区は Microsoft 365 Copilot を全庁に展開し、消極的だった職員も巻き込んで定着させた。記事によると、利用率は97%、削減時間は月約2,000時間だ（要確認。対象人数と算出方法は公開部分に記載がない）。一方、取手市は全員に一律で使わせず、意欲のある部署から広げる「取り残し作戦」をとった。利用者の約半数が、議会答弁書の作成時間を半分にしたという（要確認）。

定着に悩むクライアントには、対照的な2つの進め方として並べて示せる。※筆者見解：組織の規模と、現場の意欲のばらつきで選び分けるのが現実的だ。

大分市：国の OSS「源内」を土台に、閉域で生成 AI を動かす

ソース: キーマンズネット・2026-10-05・大分市・業界: 自治体

大分市は、デジタル庁の OSS「源内」を基盤にした生成 AI「Oita GENAI」の運用を 10/1 に始めた。例規・要綱・議会答弁・業務マニュアルを構造化したデータベースにして検索・回答する「構造化 RAG」を採用し、LGWAN の環境で動かす。データセンターは国内のさくらクラウドだ。中核市で LGWAN 上に生成 AI を置く構成は初めてとされる。

公共系のクライアントには、「閉域で、国の OSS を土台に、庁内の文書を構造化して載せる」構成の参照例として示せる。対象の職員数・費用・効果の数字は記事にない。

freee：MCP サーバーを業務委託管理に広げる

ソース: キーマンズネット・2026-10-09・freee・業界: SaaS（会計・バックオフィス）

freee は、AI エージェントから freee の API を直接操作できる「freee-mcp」に「freee業務委託管理」を加え、対応領域を11から12に広げた。契約・発注・請求・支払いのデータを AI から参照できる。今後は登録・編集の API を増やし、タスクの自動作成や請求情報の自動取得を目指すという。

国内の SaaS でも MCP への対応が進んでいる。バックオフィスの AI 活用を提案するときは、「使っている SaaS が MCP に対応しているか」を確認項目にできる。導入企業の効果の数字は記事にない。

Sophos：エージェントにも人と同じ権限の線を引く

ソース: OpenAI・2026-10-09・Sophos・業界: サイバーセキュリティ

Sophos は、1日数兆件のイベントを、9拠点の SOC が扱う1日約1,000〜2,000件の案件に絞り込んでいる。調査エージェントが文脈と脅威情報を集め、計画モデルが要約と推奨対応をアナリストに渡す。同社の申告では、調査時間が96%減り、MDR 案件の52%を AI が完結させた。顧客との契約の形（通知のみ / 協議 / 代行）ごとに、人にもエージェントにも同じ権限の範囲を適用する。

業務を AI に任せる提案では、「エージェントにも人と同じ権限の線引きを適用する」という説明がそのまま使える。権限の表を人とエージェントで分けずに1つにすれば、監査の説明もしやすくなる（※筆者見解）。数字は OpenAI の事例ページ上の自社申告である。

規制・ガバナンス

OpenAI、EU で ChatGPT の出力に透かしを入れる

ソース: OpenAI・2026-10-05・管轄: EU

OpenAI は、EU AI Act の透明性義務を受けて、EU 内の ChatGPT と Codex の出力に見えない透かしを数週間かけて入れる（全プラン）。API は一部のモデルで任意に有効にでき、既定はオフだ。同社の公表では、400トークンで約95%を検出するが、単語の25%を言い換えると検出率は17%に落ちる。クライアントには「透かしがないことは、人が書いた証明にならない」点も合わせて伝えたい。

IDCF クラウドにランサムウェア、495団体に影響

ソース: ITmedia AI+・2026-10-08 / @IT・2026-10-09・管轄: JP

IDCフロンティアの IDCF クラウド（東日本リージョン1）が 10/7 にランサムウェアの攻撃を受け、自治体を含む495の団体に影響した（@IT）。一部のゾーンは事業者側での復元が難しく、顧客のバックアップからしか戻せないとされた。セキュリティ企業3社の専門家は「AI の活用を否定する方が難しい」とみるが、AI の関与を示すログや痕跡は確認されていない。原因は対象週の時点で公表されていない。国産クラウドを選ぶ場合でも、バックアップを顧客側で持つことを調達の条件に入れるよう勧めたい。

連載: 事例深掘り「損保ジャパン、2万人の Gemini Enterprise を『試験合格＝権限』で回す」

ソース: キーマンズネット・2026-10-09・損害保険ジャパン・業界: 損害保険

損保ジャパンは、約2万人の従業員に Gemini Enterprise を展開した。システムが止まることより「使われないこと」と「誤って使われること」をリスクと捉え、権限・ログ・監視の仕組みを組み立てた。

1. 1年弱でエージェントの開放まで進めた 2025年8月に検証を始め、12月に設定の方針を決め、2026年1月にリリースした。5月にはエージェントの作成と共有を開放した。担当者によると、2026年6月時点で平日の DAU は50%超、WAU は約80%だった（要確認）。

2. 試験の合格を権限に結びつけた 利用者として登録するのは、AI リテラシーテストの合格者だけだ。人事データと合格者の名簿を日次で照合し、権限を自動で更新する。エージェントの作成と共有にも、それぞれ研修と合格を課す。入出力は Model Armor で検査し、監査ログを BigQuery に集めて部店単位の利用率を追う。

3. 標準機能の限界を、自前の仕組みで補った VPC Service Controls の下からは Workspace のスプレッドシートに直接つなげず、外部のプロキシで回避した。標準機能では共有の権限を細かく制御できず、独自の監視を作った。

4. 対比：広げたあとのコスト管理（LegalOn） 同じ週の LegalOn Technologies の事例（OpenAI・2026-10-08）は、拡大期の課題を示す。開発ツールを制限なく使わせて年間予算を超えそうになり、軽いモデルを基本に難易度で上位モデルへ切り替える運用に変えた。部門・個人ごとの月次の上限は、社内の CoE が調整する。日次の推計コストは65%減ったという（要確認。算出方法は非公表）。

提案に使うときの注意 ※筆者見解：導入期は「誰に使わせるか」、拡大期は「いくらまで使わせるか」の統制が要る、というのが2社を並べた示唆だ。損保ジャパンの例には ROI の数字がないため、効果の根拠ではなく、体制と統制の設計例として引きたい。

今週の Takeaway

  1. 大量処理の試算を作り直す。Haiku 5.5 の単価は Haiku 4.5 の10分の1で、分類や要約の費用の前提が変わった。
  2. 権限とログの設計を導入の条件にする。損保ジャパンの「試験合格＝権限」、Sophos の「人と同じ権限の線引き」、Gemini agent の「エージェント名義の監査ログ」が参照例になる。
  3. クラウドの障害に備え、バックアップを自社でも持つ。IDCF の件では、一部のデータを顧客のバックアップからしか戻せなかった。
