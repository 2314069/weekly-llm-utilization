Weekly LLM Utilization #3

Google・Meta・DeepSeek が相次いで新モデルを出した週。価格と提供形態で3モデルを比べ、茨木市の tsuzumi 2 校務実証、コーディングエージェントの効果とレビューの逼迫、声の権利のガイドラインを紹介。

この号は 2026-11-22 に後日作成したバックナンバーです。内容は対象週の時点の情報にもとづきます。

今週のハイライト

  • Google が Gemini 4 Argon を一般提供した。導入価格は入力 $2 / 出力 $10 で、12月から倍になる。
  • Meta がクローズド API の Muse Wonder と、オープンウェイトの Muse Spark Open を続けて出した。
  • 国内では、SB Intuitions が Sarashina の無償β版を公開し、NTT西日本と茨木市が tsuzumi 2 の校務実証を始めた。

技術動向

日本企業のサイトで、AI エージェントによる攻撃を観測

ソース: ITmedia AI+・2026-10-15

クラウド型 WAF のビットフォレストが、AI エージェントの攻撃かどうかを判定する仕組みを入れた。10/10 夜から 10/14 に、少なくとも3つの IP からの攻撃を確認したという。1件は8時間弱のあいだに10段階で手口を変え、約1万件の高速スキャン、既知の脆弱性への攻撃、約250件のログイン総当たりを行った。判定の手法は公開されていない。

同じ週、インドの CERT-In も、AI エージェントが権限を超えて国内組織の個人情報や機密資料にアクセスしたと公表した（TechCrunch・2026-10-16）。経路は、公開リポジトリなどに残った認証情報と、権限が広すぎるクラウドのロールだった。クライアントには「攻撃側が AI でも、守りの基本は変わらない」と説明できる。脆弱性の解消、残った認証情報の掃除、権限の絞り込みを、経営層向けの説明に入れたい。

SB Intuitions、国産 LLM「Sarashina」を無償β版で公開

ソース: ITmedia NEWS・2026-10-13

ソフトバンク子会社の SB Intuitions が、Google アカウントで使える API とチャットを無償で公開した。API では Sarashina3 の生成、大量処理、embedding、rerank、安全性判定、日英翻訳の6モデルを使える。日本語向けのトークナイザで、同じ文章を米国モデルの半分のトークン数で表せるという（同社の説明）。リクエスト数に制限があり、利用データを品質向上に使う場合があるとしている。β版の終了時期と製品版の価格は決まっていない。

国産モデルを検討するクライアントには、RAG に使う embedding と rerank まで無料で試せる、と伝えられる。ただし利用データが学習に使われうるので、機密データは入れないよう添えたい。

米国の労働時間の約90%は、ベンチマークがほぼ測っていない業務

ソース: Mercor Research・2026-10-16（ページに日付なし。HN の投稿日）

Mercor は、O*NET の923職種・18,797タスクに、公開されているエージェント系ベンチマーク29本を対応付けた。5問以上の対応があるタスクは924件だけだった。法務やコンピュータ・数理はよく測られているが、医療従事者（89職種中12）や教育（62職種中9）は手薄だ。著者自身が「暫定」としている。

クライアントには「ベンチマークの順位は、御社の業務での性能を保証しない」と説明できる。医療・教育・事務系の案件では、自社業務の評価セットを作る工程を提案に入れる根拠になる。

ビジネス活用

NTT西日本と茨木市：小中学校の校務に tsuzumi 2 をオンプレで

ソース: ITmedia NEWS・2026-10-14（一次: NTT西日本・2026-10-13）・NTT西日本 / 大阪府茨木市・業界: 公共（教育）

茨木市立の小中学校の一部で、教職員が校務文書の検索・要約、文章作成、質問応答に tsuzumi 2 を使う。GPU サーバをオンプレミスに置き、利用者の権限に応じてアクセスを制御する。期間は振り返りを含めて2027年3月31日までで、評価は教職員へのアンケートとヒアリングで行う。

自治体や教育の案件で「国産モデル × オンプレ × 権限制御」という構成の参照例になる。対象校数や削減時間はまだ公表されていないので、提案では効果ではなく構成の例として引きたい。

デジタルハリウッド大学：Claude を全学導入、学内規程も同時に整える

ソース: ITmedia NEWS・2026-10-14・デジタルハリウッド大学・業界: 教育

2026年11月から、全学生と全教職員が大学発行のアカウントで Claude を使えるようにする。制作の壁打ち、大学院の調査・論文執筆の補助、事務の効率化を想定する。あわせて、AI 利用の申告や、著作物・個人情報の扱いの学内規程を整える。大学によると、国内の大学で Claude の全学導入は初めてという。

導入と規程づくりを同時に進める型は、事業会社の全社展開にもそのまま使える。なお、契約プランと費用は公表されていない。

コーディングエージェントの効果と、レビューの逼迫

ソース: ITmedia NEWS・2026-10-16 / ITmedia NEWS・2026-10-15・Microsoft ほか・業界: IT

Microsoft 社内の数万人を4カ月追った論文では、導入初週に CLI 型のコーディングエージェントを使ったエンジニアは、マージされた PR が平均24%増え、効果が4カ月続いた（要確認）。ツール別では Claude Code が約11%増、Copilot CLI が約25%増だった（要確認）。直属の上司が使っていると、使い始めるオッズが82%上がった（要確認）。※筆者見解：Microsoft 社内の調査で自社製品の数字が良い点は、割り引いて読みたい。

別の論文は、CTO が「12カ月で生産性2倍」を掲げた米国の中規模 B2B ソフトウェア企業を追った。1人あたりの PR は2.09倍になったが、レビュアーは約1.5倍にしか増えなかった（要確認）。最終的に PR の8割超を AI ボットがレビューするようになり、人のレビューも指摘なしの承認が増えた。短期的な品質の低下（リバートの増加）は見られなかった。

展開は「管理職から使わせる」と効く。一方で生産性の目標を出すなら、レビュー体制と品質指標をセットで設計しないと、ボトルネックが移るだけになる。どちらも ITmedia 経由の数字で、論文の一次は確認できていない。

Anthropic：ジュニア比率が下がり、会議時間が増えた

ソース: Anthropic・2026-10-16・Anthropic・業界: IT（AI ベンダー）

Anthropic は自社の雇用データを公表した。2025年初めから、技術部門のジュニア比率は21%から14%に、技術職の採用に占めるジュニアの比率は27%から9%に下がった。技術部門が全社員に占める比率も61%から56%に下がった。非エンジニアもコーディングツールでソフトウェアを作れるようになったことを、理由の一つに挙げる。社員の会議時間の中央値は1年前より20%増えた。2026年4月の社内調査では、20%が「作業する側から Claude を管理する側に移った」と答えた（いずれも同社の自社データ）。

AI を最も使い込んでいる企業で、人の仕事が調整と監督に寄っている例だ。クライアントの人員計画で「ジュニアをどう育てるか」を議論する材料になる。

Replit：既定モデルを Anthropic から OpenAI に切り替え

ソース: TechCrunch・2026-10-17・Replit・業界: IT（開発プラットフォーム）

Replit の CEO、Amjad Masad 氏は、Replit Agent の既定モデルを Claude から OpenAI のモデルに切り替えたと述べた。理由は「コスト、パートナーシップ、性能」で、利用者は引き続き Anthropic のモデルも選べる。Replit は最近まで Anthropic の上位5顧客の1社だった。一方、匿名の関係者は「Anthropic との提携は続いている」と反論しており、コストの具体的な数字も出ていない。

大口の顧客でも、既定のモデルはコストと提携の条件で入れ替わる。クライアントのプロダクトでも、モデルを差し替えられる設計（複数ベンダーへの対応、評価セットの常備）にしておく価値がある、と説明できる。

規制・ガバナンス

声の権利のガイドラインと、ベンダーの外部評価

ソース: ITmedia AI+・2026-10-16 / Anthropic・2026-10-15・管轄: JP / global

日本俳優連合は「音声に関する生成 AI 利用ガイドライン」を発表した。学習・生成・公開・利用の全段階で本人の事前許諾を必須とし、一括許諾は認めず、有効期限は原則最長1年とする。出演料とは別の対価や、故人を模した音声 AI の開発禁止も掲げる。法的拘束力はない。コールセンターや広告ナレーションで音声 AI を扱うクライアントには、声の権利処理を契約に入れ、許諾の期限と撤回時の削除をデータ管理の設計に反映するよう勧めたい。

Anthropic は外部評価機関を3段階に整理した。最上位の METR は社員並みのアクセスを持ち、Anthropic は公表を拒否できない。ベンダー評価の質問票に「第三者評価の有無と公表範囲」を加える材料になる。

連載: モデル比較「今週の3モデル、比べられるのは価格と提供形態」

ソース: Google・2026-10-13 / Meta AI Research・2026-10-12 / Hugging Face・2026-10-17

今週は、Google、Meta、DeepSeek がフロンティア級のモデルを相次いで出した。価格（1M トークンあたり、入力 / 出力）、文脈長、提供形態、ベンチマークの出どころを並べる。

  Gemini 4 Argon Muse Wonder DeepSeek-V4.1-Flash-1017
価格 $2 / $10（導入価格）。12/1 から $4 / $20 $4 / $20（TechCrunch 報道、要確認） $0.15 / $0.60（DeepSeek API、時間帯で変動）
文脈長 入出力合計 1M 非公表 1M
提供形態 API、Gemini for business など クローズド API（上位版 Full は Muse Code 限定） MIT ライセンスのオープンウェイト
ベンチマーク 自社公表 数値は公式ページになし 自社公表（1世代前のモデルと比較）

1. 性能の横並び比較は、まだできない 3つとも、ベンチマークは自社公表だ。比べる相手もそろっていない。DeepSeek は DeepSWE で Opus 5 と GPT-5.6 Sol を上回るとするが、どちらも1世代前のモデルだ。Muse Wonder は数値も文脈長も公式ページに出ていない。

2. 比べられるのは価格と提供形態 Argon は 11/30 で導入期間が終わる。導入価格で PoC を回したクライアントには、12月以降の単価で TCO を出し直すよう伝えたい。DeepSeek は Argon の導入価格の10分の1以下だが、中国製モデルを使えるかを先に確かめる必要がある（※筆者見解：米国の公共部門を顧客に持つ案件は特に）。

3. オープンウェイトの選択肢も増えた Meta は同じ週に Muse Spark Open（総 816B / アクティブ 42B）を公開した。Mac Studio 2台で動くという。閉域で動かしたい案件の候補になるが、商用条件に制限のあるライセンスなので、本文の確認が要る。

提案に使うときの注意 比較表には「自社公表」「報道ベース」の区別を必ず書く。性能はクライアントの業務の評価セットで確かめる、という一文を添えたい。

今週の Takeaway

  1. モデルの比較は、価格と提供形態から始める。性能はベンダーの公表値に頼らず、自社業務の評価セットで確かめる。Replit のように既定のモデルが入れ替わる前提で、差し替えられる設計にしておく。
  2. 導入価格の期限を見積もりに入れる。Argon のように、2カ月足らずで単価が倍になる例がある。
  3. エージェントの展開は、管理職とレビュー体制から設計する。使う人を増やすだけでは、レビューにボトルネックが移る。あわせて、攻撃側の AI に備えて、残った認証情報と広すぎる権限を棚卸しする。
