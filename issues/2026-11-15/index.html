Claude Fable 5.2 と Gemini 4 の価格改定、判断モデルの登場で、モデルを工程ごとに使い分ける前提が整った週。HIS・KDDI・PwC の効果とコストの数字と、Notion AI の委託先の問題を紹介。

技術動向

「判断モデル」が相次ぐ：振り分けや可否判定を生成モデルから切り出す

ソース: Google・2026-11-11 / Strands・2026-11-09

Google は、文章を生成せず、選択肢ごとの確率と確信度を返す Gemini Decisions API を発表した。料金は100万トークンあたり入力 $0.10、出力 $0 で、遅延は150〜250ms という。用途はツール選択、ポリシーチェック、モデルのルーティングなどだ。同じ週、Amazon のエンジニア2人は、社内チケットの20分類を Claude Sonnet 4.6 から判断モデルの Strands Decider に置き換え、1件あたりのコストを約98%、平均応答時間を 4,215ms から 897ms に下げたと報告した。

クライアントには「分類・振り分け・可否判定は、生成モデルに任せなくてよい」と説明できる。エージェントのコストを見直すときは、ルーティングやガードレールの部分を判断モデルに切り出す案を出せる。ただし Strands の報告には精度の具体的な数値がない。同じ週の論文 SO-Arena は、総合性能が最も高い判断モデルでも信頼性では7位だったとしており、精度だけで選ばないよう添えたい。

OpenAI API、GPT-6 Luna に限って国内推論に対応

ソース: ITmedia AI+・2026-11-12

ITmedia AI+ によると、OpenAI API で GPT-6 Luna の国内推論（データレジデンシー）が使えるようになった。対象は Luna だけで、Responses API と Chat Completions API の従量課金に限る。利用には OpenAI への問い合わせと、不正利用監視の変更（MAM）またはゼロデータ保持（ZDR）の承認が要る。既定では、不正利用監視のため入出力を最大30日保持する。

「データを国外で処理できない」ために OpenAI を外していた金融・公共・医療のクライアントには、選択肢が増えたと伝えられる。ただし小型の Luna だけなので、上位モデルが要る用途には使えない。選定では「どのモデルが・どの API で・どの承認のもとで」国内処理になるかを確認事項にしたい。追加料金の有無と OpenAI の正式な発表文は確認できていない（要確認）。

M365 の障害で、ChatGPT と Claude のコネクタが約1日止まる

ソース: ITmedia AI+・2026-11-13

11/13 朝（日本時間）から Outlook、Teams、M365 Copilot などがつながりにくくなり、ChatGPT と Claude の M365 コネクタも動かなくなった。Microsoft は、サイバー攻撃や AI とは関係なく、ネットワーク容量の増強時に起きた問題と説明した。コネクタの復旧報告は、Anthropic が 11/14 6:49、OpenAI が 11/14 9:18 だった。

AI アシスタントの効果は、つなぎ先の SaaS が動いていることが前提になる。業務フローに組み込むクライアントには、接続先が止まったときの代替手順と、SLA がどちら（AI ベンダーか SaaS か）の範囲かを整理しておくよう勧めたい。

ビジネス活用

HIS：接客の準備を AI が整え、成約率が5ポイント上昇

ソース: ITmedia ビジネスオンライン・2026-11-13・エイチ・アイ・エス（HIS）・業界: 旅行

HIS は、来店予約した顧客が事前にサイトで見たページをもとに、AI が「関心」と「聞くべき点」を整理してコンサルタントに示す「相談予約ダッシュボード」を使っている。閲覧データはプレイドの KARTE で集める。2023年12月に都内1店舗で試し、2025年1月に全国約150店舗へ広げた。導入店舗の成約率は5ポイント上がり、2年弱その水準を保っているという。コンサルタントの約7割が日常的に使う。

試行では「AI の示唆どおりにコンサルタントが誘導してしまう」という懸念が出て、プロンプトと表示を変えた。「AI は接客の準備まで、提案は人」という分担と、成果を成約率で測る設計は、店舗型ビジネスの提案にそのまま引ける。ただし成約率の比較対象（導入前か、非導入店舗か）は記事に明記がない（要確認）。

KDDI：auショップのマニュアル検索で回答時間を90%削減

ソース: ITmedia ビジネスオンライン・2026-11-12・KDDI・業界: 通信・小売

KDDI は2026年7月、全国約2,000店舗の auショップに、6,000超の業務マニュアルから答えを探す「auセールスサポートAI」を入れ、回答時間を90%減らした。10月からは、販促物の掲示を写真で AI が判定する仕組みも全店に入れた。サポート窓口では2024年から生成 AI のチャットボットとデジタルヒューマンを使い、AI エージェントの解決率は90%に達したという。数字はいずれも KDDI SUMMIT 2026 の講演での自社発表だ。

佐々木取締役は「浮いた時間を何に使ったか」を KPI に置くとしており、効率化だけで終わらない提案の材料になる。サポートセンターの見学を100社超に行い、22件の受注につなげた話は、自社の AI 活用を外販する通信会社や SIer の型として示せる。「解決率」の定義は記事にないため（要確認）、引用するときは注意したい。

PwC の「AI だけの店舗運営」：粗利は上回ったが、LLM 利用料で赤字

ソース: ITmedia エンタープライズ・2026-11-11・PwC Japan グループ・業界: 小売（実験店舗）

PwC Japan グループは、東京オフィス内の実店舗で約2週間（2026年5/25〜6/5）、商品選定・価格設定・在庫管理・再発注を LLM の自律運営に任せ、人間の運営と比べた。AI 運営の粗利は 1,834円で人間（772円）を上回ったが、LLM 利用料が 164,846円かかり、簡易損益は −244,262円だった（人間は −157,292円）。4日目には AI が自らのコスト超過に気づいて低コストモードに切り替え、活動量が約65%減ったという。

エージェントの ROI は、業務の成果だけでなく推論コストまで含めて測らないと逆転する、という実験データとして使える。自律運営を提案するときは、任せる業務、人が監視する点、最終責任を経営者が持つことを明示するよう助言したい（PwC の提言も同趣旨）。ただし2週間の小さな実験で、販売数（50 / 48）も少なく、使ったモデルも記事にない。

ふくおかFG：「Small Win」で年20弱の AI サービスを出し、ベテランの暗黙知の聞き取りへ

ソース: ITmedia ビジネスオンライン・2026-11-13・ふくおかフィナンシャルグループ・業界: 金融（地方銀行）

ふくおかFG は2024年に AI 戦略グループを作り、既存業務の一部を AI に置き換える「Small Win」から始めた。営業店から本部への問い合わせに RAG で答える「なんでも案内AI」は、2026年2月に7領域で始めて20領域超に広げた。講演時点で、年間20弱の AI サービスを出し、所管部からの相談は約80件あるという。AI がベテランに質問して手順や例外処理を整理する「ヒアリングエージェントAI」は実証中だ。

元営業の担当者が現場と AI チームをつなぐ体制と、小さな成果で相談を増やす進め方は、地銀や地方企業向けの提案にそのまま使える。ただし定量的な削減効果は記事にない。

規制・ガバナンス

Notion AI のチャット記録が流出の恐れ：委託先が「データ非保持」を守っていなかった

ソース: Notion・2026-11-09・管轄: global / JP

Notion は、推論の委託先 Fireworks.ai への不正アクセスで、AI の利用分析機能「Insights」のチャット記録が流出した恐れがあると発表した。影響は全ワークスペースの1%未満という。Fireworks.ai とは「Insights のデータを保持しない」契約だったが、使っていたエンドポイントで保持されていた。Insights はビジネス系プランでもゼロデータ保持（ZDR）の対象外だった。国内でも 11/11 までに SecureNavi、LRM、フェイガーなどが影響の可能性を公表した。

SaaS の AI 機能を評価するときは、ZDR の対象外になる機能、推論の再委託先の一覧、委託先での保持を監査できるかを確認項目に加えたい。チャットに認証情報を入れていた利用者には、更新を勧める。

連載: モデル比較「計画は上位モデル、実行は小型・判断モデル（11/15 時点の価格）」

ソース: Anthropic 料金表 / Anthropic・2026-11-09 / Google（Carbon）・2026-11-10 / Google（Hydrogen）・2026-11-12 / Artificial Analysis

新モデルが出そろい、各社で「上位モデルが計画し、小型・判断モデルが実行や振り分けを担う」構成を組めるようになった。11/15 時点の API 価格（100万トークンあたり、USD）を並べる。

モデル 入力 / 出力 補足
Claude Fable 5.2 $8 / $40 5.1 は $10 / $50。AA 65
Claude Opus 5.5 $4 / $20 AA 59
Gemini 4 Carbon $2 / $10 12/1 から $4 / $20
Claude Sonnet 5.5 $2 / $10 AA 55
GPT-6.1 Sol $2 / $10 要確認
Gemini 4 Hydrogen $1.50 / $7.50 1M 文脈まで同一価格
Claude Haiku 5.5 $0.10 / $0.50 100K 超は $0.50 / $2.50

Gemini Decision 1 $0.10 / $0 生成しない

AA は Artificial Analysis の指数。GPT-6.1 Sol は以前の二次報道の数字。

推奨の観点

  1. 上位モデルは工程を選んで使う。 AA の計測で、Fable 5.2（Max）は1タスクあたり 42.0分・$26.54 かかった。ITmedia の実務比較でも、コストは Opus の約2倍だった（1名・各1回の試行）。
  2. 単価表だけで比べない。 キャッシュ読み取りは Fable・Opus が $0.20、Sonnet が $0.10 で、同じ文脈を繰り返し送る用途では、この差も試算に入れたい。
  3. データの処理場所を確かめる。 OpenAI の国内推論は Luna だけが対象。Claude は米国内推論に1.1倍の料金がかかる（料金表）。

※筆者見解：見積もりは「上位1つ＋小型・判断モデル」で作り、Carbon は 12/1 以降の単価で試算したい。

今週の Takeaway

  1. モデルは工程ごとに使い分ける。Fable 5.2 は難度の高い工程に絞り、振り分けや可否判定は判断モデルや小型モデルに回す。
  2. AI の効果は、推論コストと接続先の可用性まで含めて見積もる。PwC の実験と M365 の障害が、その必要を示した。
  3. AI SaaS の評価項目に「委託先のデータ保持」と「データの処理場所」を加える。Notion の件と、OpenAI の国内推論の条件が具体例になる。
