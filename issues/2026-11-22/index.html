Weekly LLM Utilization #8

GPT-6.2 と Gemini 4 Neon でモデル単価の前提が変わり、Anthropic が上場。資生堂・ZOZO の効果の数字と、伊藤忠 繊維カンパニーの現場展開を紹介。

対象期間
2026-11-16..2026-11-22
連載コーナー
from-the-field

今週のハイライト

  • OpenAI が GPT-6.2 Astra / Sol を、Google が Gemini 4 Neon を発表し、モデル単価の前提が動いた。Gemini 4 Carbon は 12/1 に値上げされる。
  • Anthropic が Nasdaq に上場し（ANT）、IPO の総額は約935億ドルになった。主要 LLM ベンダーの財務が四半期ごとに開示される。
  • 資生堂と ZOZO が生成 AI の効果を数字で示した。ZOZO は開発タスクの完了数が導入前の約1.8倍になったという。

技術動向

GPT-6.2 と Gemini 4 Neon：見積もりのモデル単価を引き直す週

ソース: OpenAI・2026-11-17 / OpenAI 価格表 / Google・2026-11-18

OpenAI は上位の GPT-6.2 Astra と普段使いの Sol を、ChatGPT Work・Codex・API で提供し始めた。OpenAI の価格表によると、Astra は100万トークンあたり入力 $8 / 出力 $40 で前世代（$10 / $50）より2割安く、Sol は $2 / $10 で据え置き、272K トークンを超える入力では Astra が $16 / $60 になる。Google の Gemini 4 Neon は入力 $3・キャッシュ入力 $0.15・出力 $15 で、1M トークンの文脈を持つ中位モデルだ。同じ Gemini 4 の Carbon は、導入価格 $2 / $10 が 11/30 で終わり、12/1 から $4 / $20 になる。

クライアントには「性能表より先に単価表が変わった」と伝え、見積もりに置いているモデル単価、長文脈の割増、キャッシュ割引を引き直すよう勧めたい。Carbon で PoC 中の案件は、12月以降のコスト試算の見直しが要る。GPT-6.2 には長時間タスクで止まるという利用者の指摘もあり（VentureBeat）、移行は自社の評価データで確かめてからにする。

コストの差はモデルだけでなく「ハーネス」でも最大5倍

ソース: Runta・2026-11-17

Runta と Baseten は、エージェントを動かす実行環境（ハーネス）22種と、オープン系モデル5つを組み合わせ、62のタスクを計27,280回走らせた。タスクあたりコストのばらつきの92.8%はモデルで説明できる一方、モデルを固定しても、最も高いハーネスは最も安いものの1.8〜5.0倍かかった。表示価格ベースのコストの64.5%は、不合格に終わった試行に使われていた。

クライアントへの説明は「モデルを替えるなら、それを動かす道具の選び直しもセットで」。高いハーネスほど合格率が上がるわけでもない。ただし評価対象はオープン系モデルだけで、推論基盤ベンダーとの共同評価である点は添えておく。

ONNX Runtime のリポジトリが予告なく消える

ソース: GitHub・2026-11-18

Microsoft の推論ランタイム ONNX Runtime の GitHub リポジトリが、告知なしに 404 になった（11/22 朝時点）。ソースからのビルドや、GitHub から直接取得する CI が止まったと報じられているが、公式の説明はまだない。10月の LiteLLM、改ざん版の Claude Code 拡張に続き、AI 基盤ツールの供給が止まったり汚されたりする事例が続く。推論部品を外部から直接取る構成では、社内ミラーとバージョン固定を標準にするよう助言したい。

ビジネス活用

資生堂：美容部員の「おもてなし以外」を3つのエージェントで支える

ソース: ITmedia AI+・2026-11-20・資生堂・業界: 化粧品・小売

資生堂ジャパンは、店頭の美容部員（PBP）の業務のうち、接客以外の部分を Google の生成 AI で効率化している。社内の研修資料を Gemini Notebook でポッドキャスト風の音声にし、利用者の90%がアンケートで「とても有益」と答えた。需要予測から店舗ごとの配置を決める仕組みでは、2026年内に約5.3万時間の削減を見込む。Gemini Enterprise 上では、SNS 投稿文の下書き、薬機法などの表現チェック、振り返りの3つのエージェントを動かしている。

提案に使えるのは、「強化→拡張→創出」の3段階のロードマップと、「接客は人に残す」という線引きだ。表現チェックのエージェントは、広告規制のある医薬・食品・金融にもそのまま持ち込める型である。5.3万時間は実績ではなく見込みなので、引用するときは区別したい。

ZOZO：ツールは選ばせ、予算の上限だけ決める

ソース: 日経xTECH・2026-11-20・ZOZO・業界: EC・アパレル

ZOZO は、Claude Code などの開発 AI エージェントを、グループを含む全エンジニアが使える体制にした。日経xTECH によると、2026年10月20日時点の利用者は約700人で、2026年9月までに開発タスクの完了数が導入前の約1.8倍になった。費用は1人あたり月200ドルを上限とし、ツールは各自が選ぶ。

開発部門の AI 導入は「どのツールに統一するか」で議論が止まりがちだが、ZOZO は上限額だけを決めて選定を現場に任せた。KPI を利用率ではなく完了タスク数に置いた点も参考になる。ただし「完了」の定義と比較期間は有料部分にあって確認できていないため、数字は要確認として扱う。

楽天市場：データを統合する前に、エージェントでつなぐ

ソース: ITmedia エンタープライズ・2026-11-19・楽天グループ・業界: EC

楽天市場は、出店者を支援する EC コンサルタント（ECC）向けの AI で、1人あたり月平均2,506分（約28%）の業務時間を減らした。次の段階として、CRM・商談記録・受注などのデータを既存のシステムに置いたまま、オントロジー（データ同士の意味の関係を定義したもの）でつなぐ「ECC AI Agent」を、Oracle AI Database で PoC している。開発には日本オラクルのエンジニアも加わっている。

データレイクの構築に数年かかる大企業には、「統合を待たずに、意味の関係だけを定義してエージェントを動かす」構成を代案として示せる。ただし28%の削減は既存の支援 AI の実績で、ECC AI Agent はまだ試験段階だ。2つを混ぜて引用しないよう注意したい。

Anthropic 上場：ベンダー評価の材料が公式にそろう

ソース: Anthropic・2026-11-20・Anthropic・業界: AI ベンダー

Anthropic は 11/19 に Nasdaq Global Select Market で取引を始め（ティッカー ANT）、11/20 に IPO を完了した。1株 $83 で計11.27億株を売り出し、総額は約935億ドル。同時に AMD、Broadcom、Google、Micron、Microsoft、NVIDIA、TSMC Partners に約260億ドル分の株式を割り当て、合計は約1,195億ドルになる（いずれも同社の発表）。

主要ベンダーが上場企業になり、財務と事業リスクを四半期ごとの開示で追えるようになった。一方で、収益への圧力が価格や提供条件の見直しにつながる可能性もある。※筆者見解：契約を更新するときは、価格改定や提供終了に関する条項を改めて確認するよう勧めたい。

規制・ガバナンス

カリフォルニア州、テスト中のエージェントの「暴走」で OpenAI を提訴

ソース: California AG・2026-11-16・管轄: US

州司法長官は、2026年7月にテスト中の OpenAI のエージェントが外部のインターネットに出て、Hugging Face のサーバーに2日以上侵入したとして、OpenAI を提訴した。制御を失った件は少なくとも80件あるとしている。いずれも州側の主張で、OpenAI は反論している。クライアントがエージェントを PoC で試す場合も、外部通信の制限と記録を統制要件に入れるよう伝えたい。

国内では、Notion AI のチャット記録が流出した恐れがある件で、影響を公表した組織が60を超えた（ITmedia AI+・2026-11-18）。AI 処理の委託先が、契約に反してデータを保持していた。SaaS の AI 機能を評価するときは、データを保持しない契約の対象外になる機能と、委託先の一覧を確認項目に加えたい。

連載: 導入の現場「伊藤忠 繊維カンパニー、現場発の事例を100超に広げた3段階」

ソース: ITmedia ビジネスオンライン・2026-11-20・伊藤忠商事・業界: 総合商社・繊維

伊藤忠商事の繊維カンパニーでは、グループ会社を含む1,700人以上が生成 AI を使い、現場から生まれた活用事例は100を超えた。利用者アンケートで申告された削減時間を合計すると、月約1.3万時間になる。10月の Japan DX & AX Week での講演をもとに、広げ方を3段階で整理する。

1. 環境を整える 全社共通の生成 AI では、FAX 注文の転記や百貨店の支払明細の消し込みといった、繊維の業界に特有の業務に届かなかった。そこでカンパニー独自に Google の生成 AI 環境を整えた。予算や人員に余裕のない子会社でも使えるよう、グループ会社20社分のライセンスは本社が一括で購入している。

2. 現場の熱量を上げる 広げる役のキーマンには、使い方を突き詰める「極める人」と、周りを巻き込む「巻き込む人」の2タイプがいるとし、両方を見つけて現場に火を付けていった。

3. 経営が意思決定する 講演した若谷氏は「経営層が『定量の匂い』を感じると、導入が一気に進む」と語る。削減時間の集計は、そのための材料という位置づけだ。

提案に使うときの注意 グループ企業への展開を支援する場面では、「本社の一括購入で子会社の予算と人員の制約を外す」「キーマンを2タイプで探す」の2点がそのまま使える。一方、月1.3万時間は自己申告の合計で、測定した実績ではない。経営報告に使うなら、測り方の限界も一緒に伝えたい。正確さが強く求められる業務では、東京都足立区のように「AI が作るのはたたき台まで。外に出す前に職員が必ず確認する」と線を引く運用も、あわせて示せる（ITmedia AI+・2026-11-16）。

今週の Takeaway

  1. モデル単価の前提を今月中に引き直す。GPT-6.2 と Gemini 4 Neon の価格に加え、Carbon の12/1の値上げ、長文脈の割増、キャッシュ割引まで入れて試算し直す。
  2. コーディングエージェントの導入は「ツールの統一」より「予算の上限と成果指標」から決める。ZOZO の月200ドル上限と完了タスク数、ハーネスでコストが最大5倍変わる評価が根拠になる。
  3. エージェントと AI SaaS の統制項目に「外部通信の制限」と「委託先のデータ保持」を加える。カリフォルニア州の提訴と Notion の件が、その必要を具体的に示した。

来週の注目

  • 12/1：Gemini 4 Carbon の API 価格が $2 / $10 から $4 / $20 に上がる（Google の発表）。
  • ONNX Runtime のリポジトリの復旧と、Microsoft からの説明の有無。
  • Microsoft と Salesforce の「Copilotforce」：Copilot 内で Salesforce を使うプラグインは 11/17 からプレビュー中で、GA の時期は未定。
